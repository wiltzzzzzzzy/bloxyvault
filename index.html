Provably Fair
Every result is derived from seeds you can verify yourself — the same inputs always produce the same outcome.

Provably Fair is a system where every game result is calculated mathematically from a set of values called seeds, instead of being decided freehand by the server. Before a round starts, the result is already locked in — the server commits to it by publishing a hash of its secret seed. Once the round ends, the seed itself is revealed, so you (or anyone) can re-run the same calculation and confirm the result wasn't changed after the fact.

Core Concepts

Server Seed
A secret random value generated by the server for the round. It determines the outcome, but stays hidden until the round is over — so it can't be picked to favor a result after the fact.
Hashed Server Seed
A SHA-256 digest of the server seed, shown to you before the round starts. It's one-way — you can't reverse it to find the seed — but once the seed is revealed, you can hash it yourself and confirm it matches, proving the seed wasn't swapped afterward.
Client Seed
A value tied to you as the player. Because it feeds into the same calculation, your side has real influence over the result too — it isn't purely up to the server.
Round Nonce
A counter that increases with every round you play, so the exact same seed pair never produces the exact same result twice in a row.

How Each Game Uses It

  • Case Battles & Cases — the full pull order for every reel is locked in and hashed before the reels ever start spinning.
  • Coinflip — the winning side is committed to before either player's coin lands on screen.
  • Dice Duel — both rolls are derived from the seed pair at the moment the duel is accepted, before either die is shown rolling.
  • Mines — the full bomb layout is committed and hashed before your first tile click.
  • Jackpot — the winning ticket is drawn from the seed the instant entries close, before the wheel animation plays.
